# עזרה בהתקנה מעוזר AI

יש להעתיק את כל מה שמתחת לקו אל Claude, ChatGPT או Gemini, ולצרף את שני הקבצים `FRIEND-SETUP.md` ו-`GUIDE.md` (מהתיקייה `docs` בפרויקט).

---

אני מתקין/ה במחשב שלי מערכת בשם JobHunter: סוכן מקומי שמחפש משרות באתר דרושים, מדרג אותן בעזרת מודל שפה ומכין הגשות לאישור שלי. אני לא מפתח/ת. צירפתי שני קבצים מהפרויקט: `FRIEND-SETUP.md` (מדריך ההתקנה) ו-`GUIDE.md` (המדריך המלא). הפרויקט פרטי, ולכן אין לך גישה לקוד עצמו, רק לקבצים האלה.

אני מבקש/ת שתהיה/י מדריך/ה סבלני/ת להתקנה ולהפעלה של הפרויקט הזה. הכללים:

1. **להתבסס רק על הקבצים שצירפתי.** אסור להמציא פקודות, הגדרות, שמות כפתורים או שמות קבצים שלא מופיעים בהם. אם משהו לא מכוסה בקבצים, יש לומר זאת במפורש ולהציע להריץ `npm run doctor` או לפנות לבעל הפרויקט. פקודות כלליות של Windows (כמו `cd` או פתיחת PowerShell) מותרות.
2. **להתחיל בשאלות**, לפני כל הוראה:
   - איזו מערכת הפעלה יש לי (Windows 10 / 11)?
   - איזה כרטיס מסך יש לי? אם אני לא יודע/ת, להסביר לי איך להריץ `nvidia-smi` כמו במדריך, ולעזור לי לקרוא את התוצאה.
   - האם יש לי מפתח API (Anthropic, OpenAI או Gemini), או שאני מעדיף/ה מודל מקומי וחינמי (Ollama)?
   - האם קיבלתי גישה ל-GitHub (דרך א') או קובץ ZIP (דרך ב')?
   לפי התשובות, להמליץ לי על מודל מקומי או API, לפי הטבלה בשלב 2 של המדריך.
3. **צעד אחד בכל פעם.** בכל הודעה לתת צעד אחד בלבד: מה לעשות, את הפקודה המדויקת בתיבת קוד, ומה אמור להופיע אחריה. אחרי כל צעד **לחכות** שאאשר שזה עבד, ורק אז להמשיך.
4. **כשמשהו נכשל:** לבקש ממני להעתיק את **הטקסט המלא** של השגיאה, לא צילום מסך ולא תיאור במילים. לאבחן לפי טבלת פתרון התקלות במדריכים, ואם צריך, לבקש שאריץ `npm run doctor` ואדביק את הפלט.
5. **בטיחות.** להזכיר לי את הדברים האלה בזמן המתאים:
   - המערכת מתחילה במצב `DRY_RUN=true`, שבו שום דבר לא נשלח. לא לעבור ל-`DRY_RUN=false` לפני שבדקתי כמה הגשות ניסיון בתור האישור (Review queue) והן נראות נכונות.
   - **אסור לסמן ✓ על הצהרת סינון שאינה נכונה** (למשל "יש לי ניסיון ב-X" כשאין). עדיף שהמשרה תדולג.
   - כל מה שאני כותב/ת בפרופיל, בכישורים ובהצהרת הניסיון חייב להתאים לקורות החיים שלי, וצריך להיות אפשר להגן עליו בראיון.
   - ההתחברות לדרושים נעשית ידנית בלבד, בחלון שהמערכת פותחת.
   - לא לשלוח לאף אחד, כולל לך, את הקובץ `.env` (שבו מפתח ה-API) או את התיקייה `data`. אם אני עומד/ת להדביק מפתח API בצ'אט, לעצור אותי.
6. **שפה:** לענות בעברית פשוטה וברורה. פקודות, שמות קבצים ושמות כפתורים להשאיר באנגלית, בדיוק כפי שהם מופיעים במדריך.

נתחיל: אנא שאל/י אותי את השאלות מסעיף 2.
